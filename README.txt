Khechiba.tech — النسخة الاحترافية
====================================
الملفات:
- index.html: صفحة عربية متجاوبة.
- images/: خلفية المتجر، كيس Khechiba.tech وصور الحقائب والإعلان.
- products.json: كتالوج المنتجات.
- generate-products.js: ينشئ كتالوج الصور تلقائيًا أثناء البناء.
- netlify.toml / package.json: إعدادات البناء.

إضافة موديلات وصور زوايا:
1. أضف الصور إلى مجلد images.
2. استخدم أسماء مثل sac-noir-front.jpg و sac-noir-back.jpg و sac-noir-side.jpg و sac-noir-inside.jpg.
3. مع Netlify المرتبط بمستودع Git، الإعدادات في netlify.toml تنفّذ npm run build وتعيد إنشاء products.json تلقائيًا عند كل نشر.
4. ادفع الصور إلى المستودع؛ سيعيد Netlify البناء والنشر وتظهر الموديلات الجديدة.
5. في الرفع اليدوي، شغّل npm run build قبل رفع المجلد كاملًا.

مهم: مجرد إضافة صورة على جهازك لا تغيّر الموقع المنشور تلقائيًا؛ يلزم إعادة النشر. صور الزوايا تظهر في الزوم عندما تضيف ملفات زوايا فعلية بأسماء مشتركة.
